# PinPoint – Pincode Lookup & Delivery Serviceability API

A backend development learning project built using **Python and FastAPI** to understand REST API development and real-world backend engineering concepts.

PinPoint aims to simplify ecommerce checkout by allowing applications to retrieve Indian address details using PIN codes and check delivery serviceability.

## Project Purpose

The purpose of this project is to gain practical experience in backend development by building an API based on a real-world ecommerce use case.

Through this project, I aim to understand how backend applications are designed, structured, and developed while learning important concepts such as API development, data validation, database management, external API integration, error handling, caching, and testing.

This project is being developed as a hands-on learning exercise to strengthen my Python and FastAPI skills and build a foundation for developing scalable backend applications.

## Learning Objectives

- Understand FastAPI fundamentals and REST API architecture.
- Work with HTTP methods, status codes, and API endpoints.
- Learn path parameters, query parameters, and request body validation.
- Implement data validation and serialization using Pydantic.
- Handle exceptions and build structured error responses.
- Integrate external APIs using HTTPX.
- Understand database operations using PostgreSQL and SQLAlchemy.
- Implement caching using Redis.
- Write unit and integration tests using Pytest.
- Learn environment variables and application configuration.
- Understand Docker and containerization.
- Explore CI/CD workflows using GitHub Actions.
